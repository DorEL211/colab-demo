# Creative Ideas

A beginner-friendly Google Colab notebook that asks for an everyday object and uses the OpenAI Responses API to suggest one unusual, practical use.

## Run it in Google Colab

1. Open creative_ideas.ipynb in Google Colab (upload it or open it from your repository).
2. Run the cells from top to bottom. The first code cell installs the OpenAI Python SDK.
3. When prompted, enter your OpenAI API key. getpass hides the key as you type; the key is not stored in the notebook source.
4. Enter an everyday object and view the single suggestion.

The notebook uses the OpenAI Responses API with model gpt-6-luna. Keep your API key private, and clear notebook outputs before sharing.
